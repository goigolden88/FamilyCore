# FamilyCore

Общее ядро семьи local-first приложений — «Дневники», «Делу Время», «Трапеза», «Финансы»: хранение в IndexedDB, синхронизация через приватный репозиторий GitHub, общие экраны, service worker, каркас стилей и сборки.

Подключается подмодулем git в `src/shared/` приложения и настраивается его `AppConfig`. Своей сборки и сайта нет.

Документы — `docs/`, начинать с `CLAUDE.md`.
