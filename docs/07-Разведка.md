## 4. «Требует внимания» — темы напоминаний

Форма у всех одна — `Topic` ядра: `{ notice: { title, body } | null, tag, target, loudKey, quietKey }`. Тем восемь:

| | Тема (`tag`) | Когда говорит | Читает сверх записей |
|---|---|---|---|
| «Трапеза» | `day` | вчера не записаны основные приёмы, сегодня пусто | **«не было» — отметки этого устройства** (`SKIPPED_KEY`, Р-29 «Трапезы») |
| «Делу Время» | `day` | за сегодня нет ни одного блока | имя экрана устройства — **только в тексте** (Р-26 «Делу Время»); говорит ли тема, от устройства не зависит. Зависит другое: идущий таймер лежит в `settings`, а не записью (Р-18 «Делу Время») — пока он идёт на телефоне, срез скажет «ничего не учтено» |
| | `review` | воскресенье и понедельник, обзор недели не проведён | — |
| «Дневники» | `overdue` | просрочено в циклах | — |
| | `illness` | открыт эпизод болезни | — |
| | `content` | зависло в «смотрю» — **не чаще раза в неделю** | **день прошлого вопроса — настройки устройства** |
| «Злотые» | `month` | с 3-го числа за прошлый месяц нет ни одной записи — слабый факт; крепче — `recordedThrough`, по какое число доведены выписки | — |
| | `recurring` | регулярные этого месяца ждут | — |

Фоновую проверку браузер будит сам, примерно раз в сутки, время выбрать нельзя (`notify.ts` ядра). Что он будит приложения одного origin разом — вывод из наблюдения человека (четыре уведомления в одно время), а не из кода. Окно со звуком — `DEFAULT_WINDOW` 12…20, у каждого приложения своё.

**Для общего напоминания через метаприложение это главное:** две темы из восьми — «Трапезы» и «Дневников» — зависят от настроек устройства, которые не синхронизируются; у «Делу Время» от устройства зависит только текст темы `day`, но идущий таймер — не запись. Срез, посчитанный на одном устройстве, у другого скажет иное. Сверх тем у «Делу Время» от устройства зависят пороги обзора `reviewStaleDays`, `reviewGoalDays` — а от них `staleTasks` и `stuckGoals` (Р-48 «Делу Время»).

## 5. Лента

`registry.feedItems` есть у всех четырёх и отдаёт `FeedItem` договора. У «Злотых» — `feedItems(data)` без дня, у остальных — `(data, day)`; у «Делу Время» `day` строки не читают. Для хроники годится; считать по ней нельзя (`02-Архитектура`, «Чего в договоре нет»).

## 6. Правила показа чисел — к ним пришли все четыре независимо

| Правило | «Трапеза» | «Делу Время» | «Дневники» | «Злотые» |
|---|---|---|---|---|
| **Число — вместе с основанием** | Р-01: `KcalSum`, «учёт в 6 днях из 7» | `MARKS_BASIS`, `PLAN_FACT_BASIS`, `YEAR_NORMS_BASIS` | Р-38, Р-44: сумма с числом отметок, среднее с числом оценённых | Р-07: `Sum.entries`, «по 142 операциям» |
| **Неизвестное — не ноль** | ккал без данных — вне суммы и названы | **модель не различает «не учитывал» и «не делал»**: минуты категории без основания `days` из `elapsedDays` в срезе соврут. Неизвестным названы `capturedOn: null`, неизвестная категория, «неучтено» — от прошедшей части окна дня (Р-21 «Делу Время») | — | «доход не внесён» вместо нуля; без курса — вне итога и названо (`missing`) |
| **Третий исход «не ясно»** | `Verdict 'open'` — дни без записей | нет: день без блоков — день без занятия. ## 8. Риски и ограничения

- **Чувствительность.** Здоровье — «Дневники»; деньги, остатки на счетах — «Злотые»; заметки и планы — «Делу Время». Метаприложение, читающее всех, собирает всё это в одном месте
- **Приложения отдаются другу** (Р-67 «Делу Время»; отдача «Злотых» — вместе с семьёй). У друга свои репозитории данных: метаприложение не должно знать их имена кодом
- **Путь чтения** — открыт после Я-11. Файл среза в репозитории данных означает токен на чтение четырёх приватных репозиториев и сеть. Прямо из IndexedDB — в обход договора, только на одном устройстве, и соединение мешает миграции соседа
- **Два `Period`.** У ядра — `{ from, to }` (`core/dates.ts`), у здоровья «Дневников» — свой, с необязательными концами. Контент «Дневников» — по году, «Злотые» — по месяцу, «Трапеза» — по неделе

## Расхождения с запиской «Дневников»

- `contentStats(entries, year)` — **по году** или по всей истории, а не за промежуток
- `healthStats` и `activityTotals` берут **свой** `Period` из `modules/health/health.ts` с необязательными концами, а не `Period` ядра
- Остальное сошлось: пять видов событий, шаг оценки 0.1 (Р-26), `cycleStates(items, events, day)` со статусами `overdue`…`unset`, `spent` и `spendTree`, `openEpisodes`, `series`, `staleWatching`, `feedItems(data, day)`, три темы напоминаний

## Что видно для формы среза — наблюдения, не решение

1. **«Число с основанием» — общий знаменатель всех четырёх.** Каждый показатель среза, вероятно, несёт основание, а не голое число. Это первый кандидат в договор
2. **Показатель бывает «не ясно» и «не известно»** — не ноль. Форма среза должна уметь сказать это без выдумывания числа
3. **Зерно разное:** день, неделя, любой промежуток, месяц, год, «на дату». Общего отрезка, на котором считают все, нет
4. **Каждое денежное число несёт код валюты.** У «Злотых» месяц и капитал — одно число в базовой валюте плюс список не вошедшего без курса; списком по валютам — только долги. База может смениться (Р-41 «Злотых»): старый и новый срезы окажутся в разных валютах
5. **«Требует внимания» уже одинаково по форме** (`Topic`, `Notice`) — самая готовая часть. Но две темы из восьми зависят от настроек устройства, а у «Делу Время» идущий таймер — не запись
6. **Свежесть — не одни часы, а несколько.** Когда посчитано; по какое число записаны данные (у «Злотых» — выписки, `loadedThrough`); есть ли курсы на дату. Прошлый месяц меняется, когда догружают выписку, прошлый капитал — когда подтягивают курсы. Срезу нужна отметка «посчитано по записям по ДД.ММ», а не только время расчёта
7. **«Не известно» — с причиной.** У «отложено» «Злотых» причин две (`no-income`, `covered`), а список незнания отчёта месяца (Р-29 «Злотых», п. 3) даёт ещё: незагруженные дни, позиции без курса, редкие платежи, категории без сравнения. Голый `null` в срезе одно от другого не отличит
8. **Отрезок — явными `from` и `to`**, а не `ГГГГ-ММ`: у «Злотых» есть `periodStartDay`, и «месяц» может перестать быть календарным
9. **Неокончательный итог** — четвёртое состояние рядом с числом, «не известно» и «не ясно»: число верное, но за записанный срок
