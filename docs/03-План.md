## Логика порядка

Ядро рождается из копии, а не пишется заново: первая версия — файлы `d86f0aa` «Делу Время» байт в байт, дальше — вынос конфига (Р-49 «Трапезы»). Так каждая строка ядра прослеживается до кода, который год работал на телефоне, а дифф выноса показывает ровно то, что стало параметром.

Проверка шва — два шага, и ни один не заменяет другой: ядро собирается и проходит тесты **без приложения рядом** (здесь), и приложение переезжает на ядро **без изменения данных** (сессией из его корня, первой — «Трапеза»).

## Этап 1 — Ядро собирается без приложения

Вопрос этапа: найден ли шов — живёт ли ядро без единого файла приложения?

1. **Документы.** «Что ядро, что приложение, что обещано семье?» `CLAUDE.md`, `docs/`, договор семьи, решения Я-01…Я-05.
2. **Коммит-копия.** «Откуда каждая строка?» `git archive d86f0aa`, 57 файлов по Я-05, байт в байт; совпадение проверено отпечатками git.
3. **Хозяева ссылок.** «Чей это Р-41?» Голые «Р-NN» — с хозяином по `05` «Делу Время», только комментарии (Я-01).
4. **Инструменты.** «Чем проверяется?» `package.json` с версиями `d86f0aa`, `tsconfig`, Vitest, CI (Я-02, Я-04).
5. **Вынос конфига.** «Что стало параметром?» `Base`, `Migration`, `AppConfig`; `createDb`, `createLayout`, `createSync`, `createImporting`; контекст для `ui/` и `screens/` (Я-03); вкладки, «Что нового», лента и импорт — параметрами.
6. **Два шва глазами.** «Где кончается механика?» `notify` — механика отдельно от правила дня; `sw.ts` — функцией; `styles.css` — каркас отдельно от экранов «Делу Время». Первая нарезка.
7. **Сборка.** «Как приложение собирается на ядре?» Фабрика конфига Vite, `icons.mjs` с параметрами, `tsconfig` для `extends`.
8. **Тесты на подставном конфиге.** «Работает ли механика без настоящего приложения?» Выдуманное приложение, переписанные `db`, `sync`, `layout`, `feed` и остальные.

**Готово когда:** в чистом клоне `FamilyCore` — `npm ci`, `npm run typecheck`, `npm test` дают код 0; поиск по ядру не находит ни `deluvremya`, ни «Делу Время» вне комментариев с хозяином, ни импорта файлов приложения; CI ядра зелёный.
